# ROAM-GS project page

Static research project page for *Go Far, Look Less*. The root `index.html` contains the page content and benchmark tables. Styles are in `css/`, browser modules in `js/`, videos and posters in `media/`, paper figures in `figures/`, and the HSSD comparison snapshots in `models/`. The font and its license are in `fonts/`.

To preview, run `python3 -m http.server 8000` in this directory and open `http://localhost:8000/`. The site can be served from the root of a GitHub Pages publishing branch or from a repository subpath.

## Dataset credits

The HSSD replays and Gaussian splats are derived reconstructions from [HSSD](https://huggingface.co/datasets/hssd/hssd-hab), by Khanna et al., under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/).

HM3D replays and figures show research results derived from the [Habitat-Matterport 3D Research Dataset](https://github.com/matterport/habitat-matterport-3dresearch), by Ramakrishnan et al. Use is subject to the [Matterport academic use agreement](https://matterport.com/legal/matterport-end-user-license-agreement-academic-use-model-data).
